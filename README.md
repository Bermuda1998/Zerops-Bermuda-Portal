# Zerops-Bermuda-Portal

Go-based deployment edition of **Bermuda Portal** tailored for [Zerops](https://zerops.io).

## Quick Start
1. Import `zerops-project-import.yml` into your Zerops dashboard.
2. Configure your environment variables using `.env.example` as reference.
3. Deploy using the included `zerops.yaml` configuration.
